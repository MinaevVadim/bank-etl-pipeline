# Bank ETL System

Производственный ETL-пайплайн для автоматизации банковской отчётности. Проект разработан в рамках практического задания от компании Neoflex.

## 🎯 Основная цель
Автоматизация формирования отчётности ЦБ РФ (форма 101) с сокращением времени подготовки отчётов с дней до минут.

## 📊 Архитектура

### Трёхслойное хранилище данных
- **DS (Detailed Storage)** — детальный слой для сырых данных из CSV
- **DM (Data Marts)** — витринный слой для агрегированных данных  
- **LOGS** — слой для метаданных и логирования ETL-процессов

### Основные компоненты
1. **ETL Pipeline** — асинхронная загрузка CSV в PostgreSQL
2. **Хранимые процедуры** — расчёт витрин и отчётности на PL/pgSQL
3. **Airflow DAG** — оркестрация ежедневных процессов
4. **PySpark Jobs** — обработка больших данных и дедупликация

## 🛠 Технологический стек
- **Python 3.10+** — основной язык разработки
- **PostgreSQL** — основная СУБД
- **Apache Airflow** — оркестрация ETL-процессов
- **PySpark** — обработка больших объёмов данных
- **asyncpg + aiofiles** — асинхронная загрузка данных
- **Docker** — контейнеризация (опционально)

## 📁 Структура проекта
```
bank-etl/

├── files/                  # Исходные CSV файлы

```

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка базы данных
```sql
-- Создание схем
CREATE SCHEMA ds;
CREATE SCHEMA dm;
CREATE SCHEMA logs;
CREATE SCHEMA rd;
```

### 3. Конфигурация
Создайте файл `.env` в корне проекта:
```env
DB_HOST=localhost
DB_PORT=5432
DB_USER=admin
DB_PASSWORD=admin
DB_DATABASE=bank_etl
```

### 4. Запуск ETL процесса
```bash
python main.py
```

### 5. Запуск через Airflow
```bash
airflow tasks test bank_etl_pipeline run_etl_process 2024-01-01
```

## 📈 Реализованные задачи

### Задача 1.1 — Загрузка CSV в PostgreSQL
- Асинхронная загрузка 6 CSV файлов
- Поддержка SCD Type 2 для версионных данных
- Валидация данных и логирование
- Обновление существующих записей

### Задача 1.2 — Расчёт витрин
- **DM_ACCOUNT_TURNOVER_F** — витрина оборотов по счетам
- **DM_ACCOUNT_BALANCE_F** — витрина остатков по счетам
- Хранимые процедуры с ежедневным расчётом
- Логирование всех этапов

### Задача 1.3 — Форма 101 ЦБ РФ
- **DM_F101_ROUND_F** — отчётная форма
- Группировка по балансовым счетам 2-го порядка
- Расчёт за январь 2018 года

### Задача 1.4 — Экспорт/Импорт
- Экспорт данных в CSV
- Модификация и импорт обратно
- Проверка целостности данных

### Задание 2.1 — Дедупликация
- Устранение дублей в витрине `dm.client`
- Реализация на PySpark с оконными функциями
- Сохранение последней актуальной версии

### Задание 2.2 — Восстановление витрины
- Анализ целостности данных в `dm.loan_holiday_info`
- Загрузка актуальных CSV на RD слой
- Полная перезагрузка витрины по прототипу
